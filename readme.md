## Cover Images

Control cover visibility independently in the `[extra]` section of `zola.toml`:

```toml
show_list_covers = true # Covers in post lists, including tag and category pages
show_page_covers = true # Top cover on article and standalone pages
```

Set either option to `false` to hide those covers. Both default to `true` when omitted. These settings do not affect OpenGraph or Twitter sharing images.
