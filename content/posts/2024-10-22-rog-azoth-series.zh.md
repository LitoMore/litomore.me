去年我第一次买了 [ROG Azoth]，它也是我的第一件 ROG 设备。
我被它的按键手感和声音吸引，于是在元旦决定买下来，作为送给自己的礼物。
今年生日的时候，我还没想好要送自己什么，直到看到一段 [ROG Azoth Extreme] 的评测视频。

<!-- more -->

### 在 macOS 上的使用体验如何？

我大部分时间都在 macOS 上使用这两把键盘。它们有 Mac 模式，所以在 macOS 上用起来没什么问题。
只要按下 Fn + Tab，就可以把 Windows/Alt 键切换为 Option/Command。
不过，设备管理软件 [Armoury Crate] 只有 Windows 版，因此其他功能就没法直接在 macOS 上设置了。

为了在 macOS 上安装 Armoury Crate，我试了不少办法：

- 使用 [CrossOver]：失败，连安装都没能完成。
- 使用 [Parallels Desktop] 运行 Windows 10/11 虚拟机：失败。软件可以安装，但更新固件时会出错。我猜是有些工具不支持 Windows on Arm。

最后我找来一台旧的 Windows 笔记本，花了五六个小时，把 Windows 10 从 1609 版本升级到 1904，才终于用上了 Armoury Crate（它要求 Windows 10 1903 或更高版本）。

### Azoth 和 Azoth Extreme 有什么区别？

首先，我买的这两把键盘用的是不同的 [ROG NX 机械轴][ROG NX Mechanical Switches]。Azoth 是青轴，Azoth Extreme 则是雪轴。

Azoth 的 OLED 屏幕是黑白的，而 Azoth Extreme 配备的是全彩 OLED 触摸屏。
不过，这块触摸屏的功能并不多，只能做一些简单的手势操作。两者的屏幕交互也都不能自行定制或编程。

另外，Azoth Extreme 采用可调节的 Gasket 结构，拨动底部的开关，就能在两种软弹手感之间切换。
如果愿意拆开键盘，也可以通过移除或更换原有的部件，进一步调整手感。
